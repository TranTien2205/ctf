# The falsifier — syntactically uniform

The log is syntactically uniform — every line the same shape, no
outlier entry, no anomaly against its own baseline → nothing to
find; reclassify.

## What uniform looks like

- Every field distribution is flat — no count outlier.
- No one-off paths, no status anomalies, no odd UAs.
- The per-hour histogram is even.
A clean log is a valid answer — record it and move to the right
class rather than force a finding.
