# Question — a scanner burst

A burst of 404s from one IP + a tool UA (nikto, gobuster, sqlmap)
+ a sequential-path pattern — the scan. The IP + time window is
the answer.

## The shape

- High 404 rate for that IP vs the baseline.
- A tool UA or a missing one.
- Sequential or wordlist-order paths.
- A tight time window (fast automated hits).
