# What NOT to do

- Don't answer "when" before checking the timezone.
- Don't answer "how many" without the denominator.
- Don't claim intent from one line — read the window.
- Don't build a baseline on one file when rotated siblings exist.
- Don't cut a field without verifying the format's columns.
- Don't grep a compressed or binary log — zgrep/parse first.

Each turns a lead into a mis-statement; the distribution-plus-window
discipline avoids them.

## The discipline in one line

Distribute before you conclude, window before you claim intent,
and quote the line rather than paraphrase it.
