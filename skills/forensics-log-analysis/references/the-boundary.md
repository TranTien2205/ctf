# Class boundaries

- "who logged in / brute-force" → dfir-authentication-trace.
- A pcap → forensics-pcap-carve.
- "reconstruct an incident from many artifacts" → dfir-*.

## The distinction

This class is extraction from a supplied log — find the line,
quote it. When the question is an incident narrative across a
bundle of artifacts (EVTX + registry + MFT + pcap), the dfir-*
family owns it.
