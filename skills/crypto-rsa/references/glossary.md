# Glossary — the terms

- `n`,`p`,`q` — modulus, primes; `phi`/`φ` — `(p-1)(q-1)`.
- `e`,`d`,`c`,`m` — exponent, private exponent, ciphertext, plaintext.
- `dp`,`dq`,`qInv` — the CRT private-key components.
- Wiener `d<n^0.25`; Boneh-Durfee `d<n^0.292`; Coppersmith `n^0.25`/`n^(1/e)`.
- batch-gcd, common-modulus, fermat, pollard-pm1, hastad, franklin-reiter, crt,
  factor-from-d, rsa-decrypt, eth-root, small-e-root, nth-root.
- LLL, CRT, CF, Bezout, PKCS pad, OAEP.
- `pow(m,e,n)==c`, `p*q==n` — the verify.

See `glossary-deep.md`.
