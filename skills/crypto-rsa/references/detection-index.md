# Detection index — the detection files, the reads

## The detection files

`detection.md` — the signal vocabulary. `detection-deep.md` — the reads.
`detection-index.md` — this file. `detection-index-deep.md` — the read→file
map. `detection-catalogue.md`/`-deep` — the keygen tells. `detection-matrix.md`
/`-deep` — the cross-table. `detection-map.md`/`-deep` — the read-order.
`detection-surface.md`/`-deep` — the artifacts. `detection-playbook.md`/`-deep`
— the commands. `detection-checklist.md`/`-deep` — the audit.
`parameter-sheet.md` — the sheet. `recon-order.md` — the order.

## The reads, in order

1. The file types — `ls`/`file`/`xxd`.
2. `RSA.importKey` — `n`,`e`,private fields.
3. The integers — `re.findall`.
4. `keygen`/`chal` — the tells.
5. `crypto_attack.py list` — the inventory.
6. The counts, `e` size, `gcd`, square, `m^e` — the cheap discriminating reads.
