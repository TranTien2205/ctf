# Length discipline

Reference module for `ctf-writeup`. Writeup material per
bug-class family or writeup section: what a proving excerpt
looks like, what the section must state, what it must never
claim. The template stays in SKILL.md.

Long enough to reproduce, short enough to read:
cut working-out, keep every falsifier that
decided a branch.

## Exit

Section done -> the template's next section.
