# Writeup depth: XML external entity

Reference module for `ctf-writeup`. Writeup material per
bug-class family or writeup section.

The `XML external entity` writeup's required shape in full:

## Repro

The steps a reader replays: intake evidence, the named
mechanism, the discriminating probe, the payload, the flag
read - each with its own excerpt.

## Evidence table

claim | excerpt | kind(class|impact) - the three-column
table every class writeup carries.

## Reviewer falsifiers

The two questions a skeptical reviewer asks of this
class's claim, and the excerpts that answer them.
