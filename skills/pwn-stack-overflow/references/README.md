## Loading rule

The `../SKILL.md` file is enough for routine recognition and the first probe.
Open `control-flow.md` when the exploit needs a concrete offset-finding or
protection-bypass shape. This class has no solved chain here yet — the file
is technique guidance, not a verified claim. For ROP chain construction see
`../../pwn-rop/` and `../../pwn-code-reuse/`.
