# Timeline reconstruction

Depth module for `ctf-osint`. Open `../SKILL.md` for the quick-reference
index first; this file is one named piece of the corpus - never a
finding by itself. Every claim still needs the live source that
produced it.

Snowflake IDs, post timestamps, wayback snapshots, EXIF datetime, WHOIS history - each source carries a timestamp family; the merged timeline often answers 'when' questions no single source can.
