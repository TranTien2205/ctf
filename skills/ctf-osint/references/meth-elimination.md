# Process of elimination

Depth module for `ctf-osint`. Open `../SKILL.md` for the quick-reference
index first; this file is one named piece of the corpus - never a
finding by itself. Every claim still needs the live source that
produced it.

Geolocation is elimination, not recognition: driving side + script + vegetation + road furniture narrows the country; then infrastructure maps and panoramas narrow the region. Each eliminated candidate is recorded.
