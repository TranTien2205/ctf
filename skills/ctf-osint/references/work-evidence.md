# Evidence standard

Depth module for `ctf-osint`. Open `../SKILL.md` for the quick-reference
index first; this file is one named piece of the corpus - never a
finding by itself. Every claim still needs the live source that
produced it.

OSINT findings live in public sources - record the URL/endpoint and the verbatim field, not a paraphrase. A screenshot text that isn't the source's own bytes is a lead, not evidence.
