# Timeline when events interleave

Routing module for `dfir-sherlock-triage`. Question text +
artifact inventory -> one depth file. The router never answers
the question; it names who does.

Questions about sequence ('what happened first', 'what
else ran that minute') route through timeline_merge -
single-artifact answers miss the sequence.
