# Host artifact: Sysmon event 22 (DNS query)

Depth module for `dfir-network-exfil-trace`. Open `../SKILL.md` for the
class contract first: first probe, falsifier, confirm shape, traps. This file
is one named piece of the corpus — never a finding by itself.

Fields: `RuleName, UtcTime, ProcessGuid, ProcessId, QueryName, QueryStatus, QueryResults, Image, User`. `QueryStatus=0` is success; `QueryResults` carries the resolved addresses. This is the HOST-side DNS tunnel record — it names the process that asked, which a pcap cannot. Windows 8.1+ only. `Image` here names the querying binary directly.
