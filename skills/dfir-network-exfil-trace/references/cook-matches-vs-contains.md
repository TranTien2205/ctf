# Cookbook: matches vs contains vs ==

Depth module for `dfir-network-exfil-trace`. Open `../SKILL.md` for the
class contract first: first probe, falsifier, confirm shape, traps. This file
is one named piece of the corpus — never a finding by itself.

`==` exact, `contains` substring (no regex), `matches` full-regex (anchored — needs .* around a substring search). Picking wrong silently changes the result set.

## Verification

Run the filter with `-Y` on the real bundle; quote matching rows verbatim.
A filter that matched nothing is a recorded negative, not a failure.
