# Workflow surface deep — the procedure plane, annotated

## The procedure surface

- **read** — the artifact → params.
- **gate** — the cheap discriminators.
- **route** — family + attack.
- **solve** — the command.
- **verify** — `x·G == Q`/`pow`.
- **record** — `post-probe` → `field-notes` → card/`attempts`.
- **escalate** — `falsifiers*` → `decide.py`.
