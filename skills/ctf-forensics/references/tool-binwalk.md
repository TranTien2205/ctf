# binwalk

Depth module for `ctf-forensics`. Open `../SKILL.md` for the
shared-file index first; this file is one named piece of the corpus -
never a finding by itself.

Signature scan + extraction - `-e` for auto-extract, the entropy view for finding encrypted/compressed regions; false positives on compressed sections are normal.
