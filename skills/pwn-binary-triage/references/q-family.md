# Question: which corruption family

Routing module for `pwn-binary-triage`. This file names the protections, the IP-control proof, and the depth file the route selects; it never writes the exploit.

Linear stack, format, heap, or a logic-gated write -
the input surface plus the crash signature names the
family, and the family names the depth file.
