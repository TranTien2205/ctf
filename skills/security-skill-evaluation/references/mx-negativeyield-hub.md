# Metric cell: negative-yield / hub

Method module for `security-skill-evaluation`. Whether a skill
in this library is actually getting better: measured by what it
changes in sessions, never by how much text it holds.

How `negative-yield` applies to a `hub` skill.

## Read

Primary-metric, secondary, or not-applicable - each skill
kind has its own decisive metrics; a router is judged on
route-accuracy, a depth on hitrate, a method on decisions
changed.
