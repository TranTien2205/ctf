# Map the filter BEFORE the escape

The challenge is the filter map, not the escape. Send single
characters and short tokens until the blocked bytes, names and node
types are known — and the layer the check runs at is named.

    1+1              does it evaluate at all?
    "".__class__     attribute access alive?
    ().__class__     parentheses + dots?
    globals()        the namespace readable?

Each error is free recon — the rejection names the layer.

## The order

Map first, escape after — the layer names the shape.
