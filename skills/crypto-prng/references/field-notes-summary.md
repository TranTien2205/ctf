# Field notes summary — the discipline the corpus encodes

## The record contract

- **`predict == held-back`** — the only accept. A return value, a
  "plausible" state, a training-output match — none are a recovery.
- **the falsifier is a result** — `gcd→0`, `L≈n/2`, `predict!=held`,
  `<count` — record the kill + `reopen_if` in `attempts/`; don't re-run
  the same model.
- **the flag is the response** — `flag{`/`CTF{` from the forged/
  decrypted object, not the description text.
- **the budget is bounded** — 5 probes / 15 min per mechanism; a
  falsifier ends the mechanism — `attempts` + `decide.py` the next rung.

## The honest status

`catalogue` class — no `knowledge/chains/` card for `crypto-prng`. The
corpus is standard mechanism + field procedure. Promote to `verified`
only through a real `classify_solve` → chain card → `field-notes`
`confirmed`.

## The five-line workflow

```
name the generator → meet the count → normalize to raw
→ the matching attack → predict==held → use → flag
```
