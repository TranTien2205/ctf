# SSRF Depth Skill

Confirm that a server-controlled fetch occurs with one controlled URL or a
documented internal boundary. Record protocol, host, port, path construction,
redirect behavior, and response visibility. Then reason from the source about
the flag-reaching internal route. Use bounded timeouts and stop after three
non-signaling probes before lowering priority.
