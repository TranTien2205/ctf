# Deep: fetcher URL parsing

Depth module for `ctf-web`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

Different fetchers split userinfo/host/port/fragment differently: user@host, host#frag, host\\path, IPv6 [] literals - each boundary is a candidate for the allowlist miss.
