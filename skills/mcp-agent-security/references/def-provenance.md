# Audit: provenance

Public source, a pin-able commit or tag, a license, a maintainer
with a track record - a server that cannot be pinned cannot be
reviewed; a moving branch is a moving target.

## Check

Repo URL, commit hash recorded, license file present, last-commit
age, maintainer identity resolvable.

## Finding shape

Unpinnable source or anonymous provenance is a reject, not a risk
rating.

## Pivot

Module read -> the base reference files or the class boundary it names.
