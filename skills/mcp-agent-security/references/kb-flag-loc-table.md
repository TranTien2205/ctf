# Flag-location decision table

Depth module for `mcp-agent-security`. The model's own text
is never evidence of a flag.

In system prompt -> extraction families; behind a tool
-> drive the call; in a file -> route the read; in env
-> which tool can read env. The location named in the
challenge text picks the row.

## Pivot

Module read -> the base reference files or the class boundary it names.
