# The agent as the caller

Depth module for `mcp-agent-security`. The model's own text
is never evidence of a flag.

In a challenge, the agent is the privileged caller
between the user and the flag - the injection's job
is to become the instruction the agent's tools
execute. The flag's location names which tool
needs driving.
