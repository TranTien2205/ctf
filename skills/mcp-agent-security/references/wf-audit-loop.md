# Defensive audit loop

Provenance -> permission-vs-purpose -> injection surface ->
auto-exec set -> supply chain -> schema truthfulness ->
credential exposure -> logging. Each row produces a pass,
a risk rating, or a reject.

## Output

The per-tool inventory table plus the reject list; the
audit is a decision record, not a vibe.

## Pivot

Module read -> the base reference files or the class boundary it names.
