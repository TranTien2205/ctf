# Map-first workflow

The tool list before any injection: enumerate, classify each
tool by sink (fs/net/shell/cred), mark the unconfirmed set,
mark which tools ingest untrusted content. The chain is
chosen from the map, not guessed.

## Map fields

name | purpose | sink | confirmed? | untrusted input? |
output path | risk.

## Pivot

Module read -> the base reference files or the class boundary it names.
