# Corpus close: using the corpus under load

This corpus is a reference, not a checklist to recite. Under contest load the
discipline is: name the half (offensive probe vs defensive audit), open the
one module the task names, do the module's discriminating step, and go back.

## What the corpus is NOT

- Not a substitute for `../SKILL.md`'s two-half framing - the module assumes
  the half is already decided.
- Not evidence. A module's claim is a hypothesis until the task's own tool
  result or verifier confirms it.
- Not a substitute for `../field-notes.md` - real experience goes there,
  and the corpus stays catalogue until it does.

## The one-rule reminder

The model's own text is never evidence of a flag. On the offensive side, the
tool result or the challenge verifier confirms. On the defensive side, the
audit's table of verbatim observations is the finding. Everything else is a
hypothesis with a falsifier, and this module is the reminder of which side of
that line the current claim sits on.

## When in doubt

Re-open `../SKILL.md`. The routing section names the sibling skills this hub
hands off to, and `../../LOOP_DISCIPLINE.md` owns the budget this file does not.
