# Param discovery: jsonvsform

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

JSON-vs-form object injection surface: when the
body parser accepts objects, operator-shaped values
({"$gt":""}, {"$ne":null}, __proto__) reach the query layer
- that is the nosqli/prototype prediction, recorded as 'object
params accepted' with the verbatim 200 response. Recon names
the shape; the depth skill names the bug.
## Pivot

Signal harvested -> out-*; route named -> that skill.
