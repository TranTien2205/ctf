# Class recheck: race

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Recon evidence web-race-condition needs: endpoints
with check-then-act semantics (redeem, transfer, vote, apply,
coupon, balance ops), single-use object surfaces (codes,
tokens), idempotent-looking POSTs, and timing windows the
flow implies. The race_probe serial baseline is the first
measurement the skill wants.

Signal harvested -> out-*; route named -> that skill.
