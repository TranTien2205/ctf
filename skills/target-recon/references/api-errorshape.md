# API recon: errorshape

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Error shape reading: {detail:...} = FastAPI/
DRF; RFC7807 application/problem+json = Spring/modern;
{error:{message,stack}} custom; HTML error = page app not
API. Stack traces in errors = debug posture + version leak.
A 400 revealing expected param names is parameter discovery
for free - record every leaked field name.

Signal harvested -> out-*; route named -> that skill.
