# Signal x class: content-type / smuggling

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Whether the `content-type` signal raises `smuggling` on the
router's priors.

## Read

Strong-hint, weak-hint, or no-signal - the observation's
weight toward that class. Weak hints combine; strong hints
name the first probe family.
