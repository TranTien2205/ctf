# Class recheck: logic

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Recon evidence web-logic-flaw needs: the business
flow map (order of steps: cart->checkout->pay->confirm),
quantity/price/state fields client-visible, skip-a-step
surfaces (direct deep-link to later steps), numeric
boundaries (0, -1, overflow), and replay-able operations.
## Pivot

Signal harvested -> out-*; route named -> that skill.
