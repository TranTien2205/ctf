# Class recheck: ssti

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Recon evidence web-ssti needs: a request value rendered
into a template response (echo of input inside generated
markup), the engine prior (Jinja/Twig/Freemarker/EJS from
stack+errors+file types), error on template syntax ({{7*7}}
shape only as a marker probe is the skill's job - recon
delivers the render points and engine identity).
## Pivot

Signal harvested -> out-*; route named -> that skill.
