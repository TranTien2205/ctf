# CTF-specific recon: instancepattern

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

CTF instance shape: http://<ip>:<random-port>
or <name>.<event>.ctf - ephemeral, single-purpose. Recon
meaning: the whole app IS the challenge - default pages are
author-placed, the 'generic' surface is curated. Oddities are
deliberate: a weird endpoint or stray comment is the intended
door, not noise. Record everything unusual.
## Pivot

Signal harvested -> out-*; route named -> that skill.
