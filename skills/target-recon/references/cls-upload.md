# Class recheck: upload

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Recon evidence web-file-upload needs: upload
endpoints and forms (enctype, field names, max size hints),
the storage location question (where do uploads land -
/uploads, CDN, api response URL?), accepted type/extension
claims in errors or JS validation, and post-upload retrieval
path predictability.
