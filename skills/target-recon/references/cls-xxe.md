# Class recheck: xxe

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Recon evidence web-xxe needs: XML acceptance surfaces
(text/xml or application/xml content-type, .xml endpoints,
SOAP, SAML posts, docx/xlsx upload that parses XML), the
parser identity hints (libxml/dotnet/Java/SAX from stack),
and file/entity-bearing fields in the discovered XML shape.
