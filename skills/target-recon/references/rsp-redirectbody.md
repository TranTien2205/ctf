# Response reading: redirectbody

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Redirect-body reading: Location target
verbatim (same-host? cross-host? param-shaped?), meta-
refresh and JS-redirect fallbacks in the body, status
(301 permanent vs 302 vs 307 method-preserving) - each
tells a different story about the flow.
