# Error depth: debugmode

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Debug-mode posture: traceback pages, X-Debug-*
headers, django-debug-toolbar, werkzeug /console, Next.js dev
overlays, source maps shipped. Each is a surface observation;
debug mode also means verbose error oracles = the whole
enum gets cheaper.
