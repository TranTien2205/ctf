# Response reading: lengthdelta

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Length-delta reading: response length is the
cheapest oracle - same status different length = different
content = different code path. Calibrate the baseline first
(word-calibrate); deltas of a few bytes can be timestamps -
find the MINIMUM meaningful delta before trusting it.
