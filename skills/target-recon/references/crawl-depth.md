# Crawl strategy: depth

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Crawl depth discipline: depth 1 = linked pages only,
depth 2 when the surface is thin. Pages discovered get their
assets read (JS endpoints, comments, meta) - one page's links
are free enumeration. Depth beyond 2 on a shared instance
needs justification per scope.
## Pivot

Signal harvested -> out-*; route named -> that skill.
