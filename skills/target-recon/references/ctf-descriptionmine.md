# CTF-specific recon: descriptionmine

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Challenge-description mining: the category
tag (web/crypto/...), the flavor text's tech hints ('my first
express app', 'custom protocol', 'admin bot'), attachments =
the author's intended stack. The description is the strongest
prior - it constrains what recon should look for.
## Pivot

Signal harvested -> out-*; route named -> that skill.
