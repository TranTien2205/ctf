# Authenticated recon: rolediff

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Role diffing: when two credentialed accounts exist,
request the same surface map as each - the delta (routes one
sees and the other does not) IS the authorization boundary map.
Admin-only menu paths in HTML, role claims in tokens, and
403-vs-404 patterns on gated routes are all recorded as
separate observations.
## Pivot

Signal harvested -> out-*; route named -> that skill.
