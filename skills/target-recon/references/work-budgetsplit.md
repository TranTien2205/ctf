# Recon workflow: budgetsplit

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Budget split: recon gets the small share -
three commands intake, ~10-20 targeted probes maximum before
classify runs. A recon that wants 200 requests has failed its
purpose; the answer is in reading, not volume. Enumeration
requests beyond that need a named question each.
## Pivot

Signal harvested -> out-*; route named -> that skill.
