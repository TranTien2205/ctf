# Param discovery: cookieparams

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Cookie-parameter crossover: cookie values that
mirror request params (role=user, admin=0) are re-feedable
inputs. Shape analysis first (session_dissect) - a signed
cookie is not a free param; a plaintext role= is. Record the
cookie names and shapes verbatim.
