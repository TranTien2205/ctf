# Crawl strategy: jsneeded

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

JS-rendered crawl decision: when the HTML shell
is empty and JS builds the DOM (React/Vue/Next shells, empty
<div id=root>), the real content needs a browser or the data
endpoints JS calls - usually /_next/data or /api/*. Read the
bundle first; render only when the bundle can't be read.
## Pivot

Signal harvested -> out-*; route named -> that skill.
