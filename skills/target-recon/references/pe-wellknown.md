# Path enum: wellknown

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Well-known probes: /.well-known/security.txt
(disclosure policy = scope hint!), /.well-known/openid-
configuration (oauth endpoints = full auth map), /.well-known/
jwks.json (key material shape), /humans.txt, /security.txt,
/assetlinks.json, /apple-app-site-association (mobile links).
