# Baseline calibration: dead404

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

404 baseline: request 3 invented paths of varying
depth - capture status/length/body-hash. This IS the dead-
shape: every later probe diffs against it. A 200-everything
server needs a different discriminator (length/content) -
establish which before enumerating.
