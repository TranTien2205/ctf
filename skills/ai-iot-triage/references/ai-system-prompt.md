# The system prompt's role

Routing module for `ai-iot-triage`. AI and IoT share nothing but the label - this file names the sub-type and the router that owns it; it never solves.

Hidden instructions often carry the flag or the boundary -
extraction targets the instructions; the model repeating
them is the evidence, verified against the challenge
verifier.
