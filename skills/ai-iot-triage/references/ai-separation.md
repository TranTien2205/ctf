# The separation test

Routing module for `ai-iot-triage`. AI and IoT share nothing but the label - this file names the sub-type and the router that owns it; it never solves.

Ask for the instructions directly, once - the cheapest probe in
the AI branch. A model that prints its system prompt on request
is a one-probe challenge; most are not, and the refusal names
the next layer.
