# AI-side evidence rule

Routing module for `ai-iot-triage`. AI and IoT share nothing but the label - this file names the sub-type and the router that owns it; it never solves.

The model's text is never evidence - the tool result or the
challenge verifier confirms. The single most common
fabrication source in this category.
