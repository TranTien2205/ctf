# Reading order

Depth module for `ctf-misc`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

SKILL.md -> `ctf-misc` router names the carrier (jail, encoding, game/VM, RF, data-hiding, puzzle) -> the family shared file -> the class skill (misc-interpreter-escape / misc-encoding-carrier / misc-constraint-puzzle) once the class is named. Class skills win once the class is named.

## Pivot

Module read -> the shared file or class skill it names.
