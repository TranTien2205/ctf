# Class boundary

Depth module for `ctf-misc`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

The ctf-* reference is the fallback for shapes that fit no class - esoteric languages, game VMs, RF captures, platform tricks, puzzle formats. Once the class is named its skill owns the depth.

## Pivot

Module read -> the shared file or class skill it names.
