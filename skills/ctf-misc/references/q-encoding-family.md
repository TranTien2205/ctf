# Question: which encoding family

Depth module for `ctf-misc`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

Count the alphabet: pure hex -> base16; A-Za-z0-9+/= -> base64; A-Z2-7 -> base32; no-0OIl -> base58; dense mixed -> base85/91; pairs of digits 1-5 -> tap code; ACGT only -> DNA; dots/dashes -> morse. The alphabet is decided BEFORE the decoder is chosen.
