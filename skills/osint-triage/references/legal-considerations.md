# Legal & Ethical Considerations

## Allowed (Public Sources)

- Certificate transparency logs
- LinkedIn public profiles
- Job postings
- Public GitHub repositories
- DNS records
- WHOIS data
- Search engine results

## Grey Area (Check Scope)

- Leaked credential databases (may contain PII)
- Social engineering (phishing simulations)
- Testing credentials on login portals (may trigger alerts)

## Not Allowed (Out of Scope)

- Active scanning before written authorization
- Social media impersonation
- Credential stuffing on production systems without permission

**Always confirm scope with client before testing found credentials.**
