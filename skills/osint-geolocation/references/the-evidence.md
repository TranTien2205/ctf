# Evidence — the matching detail

- The verbatim matching detail (a sign, a plate, a landmark).
- The public source (street imagery, a map) showing the same.
- A coordinate only as strong as the feature it rests on.

## Verbatim

The matching detail + the source — the place names itself through the unique feature.

## The grade

The same unique feature in a public source — the strongest grade short of an embedded GPS.
