# csrf vs cors

Routing module for `web-triage`. This file discriminates - it says which bug class a signal raises and which probe separates the candidates. It never proves a class; proof belongs to the depth skill the route names.

CSRF is the browser sending a credentialed cross-origin request the endpoint accepts; CORS is the response's access-control headers letting a foreign origin READ. Write-shape is csrf, read-shape is cors.
