# Question: what would change my mind

Routing module for `web-triage`. This file discriminates - it says which bug class a signal raises and which probe separates the candidates. It never proves a class; proof belongs to the depth skill the route names.

Each candidate class carries the response that would demote it - the falsifier. State it before probing; an observation that matches no hypothesis is inconclusive, not a confirmation.
