# Negative: stale observation

Routing module for `web-triage`. This file discriminates - it says which bug class a signal raises and which probe separates the candidates. It never proves a class; proof belongs to the depth skill the route names.

The signal came from a cached page, an old bundle, a different vhost - re-verify against the live target before routing on it. A stale signal sends the whole route wrong.

## Pivot

Module read -> the sibling module the observation names, or the depth
skill the route selects.
