# xss vs xs-leaks

Routing module for `web-triage`. This file discriminates - it says which bug class a signal raises and which probe separates the candidates. It never proves a class; proof belongs to the depth skill the route names.

Reflection into HTML+viewer says xss; an HttpOnly cookie plus a bot with no readable flag path says xsleaks - the oracle is an error/timing difference, not a stolen token. Check whether the flag is reachable by script before routing xss.
