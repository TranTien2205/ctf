# UserAssist — GUI launches, ROT13 names

The value name is the path ROT13'd; 72-byte blob: run count at 0x04,
focus ms at 0x0C, last-exec FILETIME at 0x3C. XP is 16 bytes, count
at 0x04, FILETIME at 0x08, counter starts at 5 (subtract). GUI
launches only — a console command's absence is not an answer.

## GUI only

ROT13 names, count at 0x04, XP starts at 5.
