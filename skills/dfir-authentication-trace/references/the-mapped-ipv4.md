# IpAddress forms — ::ffff: mapped v4

`::1` is local; `::ffff:10.0.0.12` is a mapped IPv4; port `0` for
interactive, nonzero = arrived over a socket. Normalize before
comparing two records' addresses.

## Normalize

::ffff: mapped v4; port 0 = interactive.

## The port

Nonzero port = a socket arrival.
