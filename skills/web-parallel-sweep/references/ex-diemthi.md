# Example: the eleven-layer challenge

Method module for `web-parallel-sweep`. The sweep splits a web target by bug-class family into bounded measurements; this file is one named piece of that method. Ten families reporting is not ten families closed.

The CSCV2026 diemthi case the method cites: eleven mechanism
layers each closed by a cheap read-only measurement, serially,
and lost on the clock. The sweep exists because those eleven
measurements were independent.
