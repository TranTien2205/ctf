# Class assignment: cachep -> parser

Method module for `web-parallel-sweep`. The sweep splits a web target by bug-class family into bounded measurements; this file is one named piece of that method. Ten families reporting is not ten families closed.

`web-cache-poisoning` is assigned to the `parser` family.

## Why this family

The grouping is by probe: this class's first discriminating request
is the same shape the family's other classes send, so one agent
measures them together. The class's own depth skill owns the
exploit detail; the family owns the bounded measurement.

## Depth handoff

Family open -> `../../web-cache-poisoning/` for the class-level
probing detail.
