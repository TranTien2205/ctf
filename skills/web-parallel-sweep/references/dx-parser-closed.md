# Cell: parser -> closed

Method module for `web-parallel-sweep`. The sweep splits a web target by bug-class family into bounded measurements; this file is one named piece of that method. Ten families reporting is not ten families closed.

What a `closed` disposition from the `parser` family means.

## Read

closed - the family's falsifier held; record the measurement in the
kill map. open - the falsifier broke; the family's next_probe field
and its class's depth skill take over. not-measured - the probe
never ran; unspent budget, not a negative. parked - no
source_signals fired; the cheapest possible outcome, already
decided at split time.

## Ledger step

The disposition decides which hooks.py command --merge prints for
this family and what the next decide.py call should see.
