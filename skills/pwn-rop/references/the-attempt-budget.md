# The attempt budget — five chains


The ceiling is five chains per the SKILL.md budget — on exhaustion:

- Report each chain measured dead with the measurement that killed
  it.
- tools/decide.py answers escalate rather than ending the challenge.
- The kill map goes to knowledge/attempts/.

## The rule

A chain failing the same way twice isn't a new chain — it's a
re-run; a variant must change a mechanism, not a byte.
