# The order of work — the build sequence — checklist

Companion to `the-order-of-work.md`.

## Checklist

- [ ] 1. Triage (protections, gadgets, imports).
- [ ] 2. Measure the offset.
- [ ] 3. Choose the ending.
- [ ] 4. Source the string and the functions.
- [ ] 5. Pack the chain.
- [ ] 6. Verify under the debugger.
- [ ] 7. Fire.
