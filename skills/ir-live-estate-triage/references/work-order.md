# Recovery vs investigation order

Routing module for `ir-live-estate-triage`. A live estate
already hit: services down, encrypted files, a note, a clock.
The router bounds the intake so evidence survives, then routes
to one dfir-* class.

Evidence capture before restore where the clock allows:
a wiped disk answers nothing after rebuild. Availability
still outranks - capture cheap, restore fast, analyze
during service uptime.

## Pivot

Signal named -> its sig-* module; evidence safe -> route-*.
