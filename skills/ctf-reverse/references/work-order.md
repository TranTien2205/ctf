# Reading order

Depth module for `ctf-reverse`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

SKILL.md index -> the ONE shared file matching the binary shape (patterns* for what the code does, tools* for what reads it, anti-analysis* for what fights you) -> the class skill (rev-native-check / rev-bytecode-vm / rev-managed-code) once the class is named. The shared files are depth, not a second router.
