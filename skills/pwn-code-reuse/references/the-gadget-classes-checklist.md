# The gadget classes — a field guide — checklist

Companion to `the-gadget-classes.md`.

## Checklist

- [ ] pop — the register setters (the commonest).
- [ ] mov-store / mov-load — memory ops.
- [ ] xor — zeroing.
- [ ] call/jmp — transfers.
- [ ] leave/xchg/add — pivots.
- [ ] syscall/int — kernel entries.
- [ ] ret — alignment.
