# Deletion: Browser/SQLite rows surviving

Depth module for `dfir-antiforensics-trace`. Open `../SKILL.md` for the
class contract first: first probe, falsifier, confirm shape, traps. This file
is one named piece of the corpus — never a finding by itself.

Downloads, history, cache records in SQLite survive file deletion until vacuum — a deleted download still names its URL and target path in the browser DB. Secondary corroboration for what left.

## Evidence rule

Deletion evidence is a record pair: the delete event/journal row AND the
surviving artifact that proves it was deleted, not merely absent. A missing
file alone is never the record.
