# The observable picks the attack

Depth module for `ctf-crypto`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

n/e/c values -> RSA shapes; a curve's params -> ECC; a keystream/oracle -> symmetric; a seed/state -> PRNG; a classical-looking ciphertext -> classical. Wrong observable-to-attack mapping is the common failure, not wrong math.
