# Preconditions are numbers

Depth module for `ctf-crypto`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

Each attack's precondition is a measurable property: p and q close (Fermat), e*d known (Wiener/Boneh-Durfee bounds), shared n (common modulus), nonce reuse (ECDSA) - measure the precondition first, the attack is arithmetic after.
