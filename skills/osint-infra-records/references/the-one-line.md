# The one rule

Every record type can carry the answer — TXT is just the usual
one. Sweep the types, pull the SANs, and quote the verbatim
answer.

## Why not stop at A/AAAA

A/AAAA only name the host's address — the answer lives in the
data-carrying types (TXT, SPF, SRV) and the certificate's SAN
list. The host's address is never the flag.

## The falsifier pair

Wildcard inflation or an all-operational set — either closes the live records; then it is history or another class.

## The order

TXT, SANs, whois, AXFR — the coverage that finds the flag.
