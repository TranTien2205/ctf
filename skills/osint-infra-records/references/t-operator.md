# Naming the operator

NS hostnames (ns1.<operator>.com), SOA rname, the whois contact —
together name the DNS operator; a shared operator links sibling
domains.

## The signals

- `ns1.cloudflare.com` style — the DNS provider.
- A custom `ns1.<the-domain>` — self-hosted DNS.
- The SOA rname — the admin email (`.` for `@`).
- The whois registrant — the owner pattern.
