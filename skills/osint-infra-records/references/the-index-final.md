# Corpus index — infra records

the-* files hold the workflow, record types, sources, techniques
(t-*), discipline and worked examples; the matrices map
record×question and source×question. Start at the-workflow.

## Structure

- the-workflow / the-map-index — the route.
- the-<record>-detail — each record type.
- t-<topic> — techniques (syntax, authoritative, chains, cert).
- the-* worked examples.
- Per-format matrices — record×question and source×question.

## Where the answer lives

Usually: a TXT, a SAN, or a planted record — the first-three queries cover most of it; the matrices map the rest.

## The shape

Matrices map the space; the-* files hold the method; the worked examples show the path. Start at the-workflow.
