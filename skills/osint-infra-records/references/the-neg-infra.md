# Negative — all operational

Every record only operational data, cert names no new host → the
answer isn't live; pivot to crt.sh/archive/passive or reclassify.

## The pivots

- crt.sh — historical SANs for a name that's gone.
- archive.org — the site's past content.
- Passive DNS — a resolution that's ended.
- The live service — the answer may be web-side, not a record.

## Reclassify
