# Encodings layer

Depth module for `ctf-misc`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

CTF carriers stack: base64 inside rot13 inside hex - decode ONE layer at a time and re-measure the alphabet after each; the layer that suddenly produces text is the last cipher layer, not necessarily the last encoding.
