# The carrier names the family

Depth module for `ctf-misc`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

An interactive shell -> jail shapes; a blob of text -> encoding carrier; a binary protocol or save -> game/VM; an IQ/capture file -> RF; a service with odd constraints -> puzzle. The input shape, not the challenge title, decides.
