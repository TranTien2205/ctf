# Alphabet identification

Depth module for `ctf-misc`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

The char set names the encoding family first: 0-9a-f hex, A-Za-z0-9+/= base64, A-Z32 base32, no-0OIl base58, binary run-length, brainfuck 8-char, esoteric symbol sets - encodings.md carries the table.
