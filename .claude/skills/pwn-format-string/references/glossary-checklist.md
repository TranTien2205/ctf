# Glossary — the vocabulary — checklist

Companion to `glossary.md`.

## Checklist

- [ ] Term | Meaning
- [ ] format string | the first arg to printf — the program
- [ ] specifier | %p %x %s %n %hn %hhn — the opcodes
- [ ] %N$p | read the Nth argument
- [ ] %N$s | deref the Nth argument
- [ ] %N$n | write count to *Nth-arg
- [ ] arg offset | which N reads your input
- [ ] count | bytes printed so far — the %n value
- [ ] GOT overwrite | %n into a GOT slot
- [ ] hook | __malloc_hook/__free_hook (glibc ≤2.34)
- [ ] positional arg | %N$... — addressed by index
