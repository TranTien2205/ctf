# Hash identification

Depth module for `ctf-forensics`. Open `../SKILL.md` for the
shared-file index first; this file is one named piece of the corpus -
never a finding by itself.

Hash length/charset names the family: 32-hex MD5-ish, 40-hex SHA1, 64-hex SHA256, $2y$ bcrypt, $6$ sha512crypt - name before crack (john/hashcat both present).
