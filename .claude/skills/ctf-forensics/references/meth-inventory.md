# Inventory before claims

Depth module for `ctf-forensics`. Open `../SKILL.md` for the
shared-file index first; this file is one named piece of the corpus -
never a finding by itself.

`artifact_inventory.py --path <dir> --hash` names which artifacts exist - absence claims ride on the inventory, not on a failed parse.
