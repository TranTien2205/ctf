# ROP evidence — what counts — checklist

Companion to `the-evidence.md`.

## Checklist

- [ ] The triage's protections report — the route's basis.
- [ ] The /R or --gadgets listing — the chain's vocabulary.
- [ ] The leak — a pointer-range value.
- [ ] The r2 -d walk — the chain landing.
- [ ] The observable — the call's effect.
- [ ] The flag — through hooks.py pre-flag.
- [ ] A gadget remembered from another binary.
- [ ] A clean exit after the chain.
- [ ] A crash "close to" the target.
