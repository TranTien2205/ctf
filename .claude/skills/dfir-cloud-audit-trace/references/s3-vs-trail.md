# S3: Server access log vs CloudTrail

Depth module for `dfir-cloud-audit-trace`. Open `../SKILL.md` for the
class contract first: first probe, falsifier, confirm shape, traps. This file

Per the AWS logging-options comparison: authentication failures and lifecycle transitions/expirations/restores appear in server access logs and NOT in CloudTrail; CloudTrail does deliver AccessDenied and anonymous requests. The two logs are complementary, not redundant.
