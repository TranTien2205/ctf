# Recording — what goes in field-notes — checklist

Companion to `the-recording.md`.

## Checklist

- [ ] The format (.pyc/.wasm/custom-VM) + version.
- [ ] The decode method (marshal+dis / table recovery / trace).
- [ ] The check's transform.
- [ ] The produced input + the verdict output.
- [ ] The traps hit (version mismatch, runtime table).
