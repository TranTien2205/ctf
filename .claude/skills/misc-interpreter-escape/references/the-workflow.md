# The workflow — map, shape, escape

1. Probe `1+1`, `"".__class__`, `()` chains — does it evaluate?
2. Send banned chars/tokens — name the layer from the error.
3. pyjail_gen with the bans -> the surviving shapes.
4. Choose the shape for the layer; enumerate the index live.
5. Confirm by an observable effect.

## The chain

Evaluate? -> name the layer -> pyjail_gen -> shape -> live index -> effect.

## The order

Map -> name the layer -> filter the corpus -> shape -> index -> effect.

## The discipline

The layer names the shape; the map is the challenge.
