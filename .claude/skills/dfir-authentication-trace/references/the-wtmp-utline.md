# wtmp ut_line — pts vs tty vs :0

`ut_line` `pts/N` = a remote/session terminal, `ttyN` = console,
`:0` = X session — the line separates local from remote logins the
same way LogonType does on Windows.

## The line

pts/tty/:0 separates remote from local.
## Terminal

pts/tty/:0 = remote/console/X.
