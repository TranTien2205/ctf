# 4964 — the special-groups watch list

`SidList` joined by `LogonGuid`; the watch list is the `SpecialGroups`
string under `HKLM\...\Lsa\Audit`, SIDs `;`-delimited (Microsoft
Learn, 4964).

## The watch

SidList by LogonGuid; SpecialGroups names the watched SIDs.

## The list

SpecialGroups names the watched SIDs.
