# Enumeration vs spray — the name count

0xC0000064 over MANY TargetUserNames from one IpAddress = name
enumeration (answer: the distinct-name count or first tried);
0xC000006A against ONE name = password attack (answer: the attempt
count or last 4625 before the 4624).

## The answer

Distinct-name count vs attempt count — the names decide.
## Names

Many names vs one name.
