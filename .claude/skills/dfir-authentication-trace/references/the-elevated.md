# ElevatedToken + ProcessName — what the session carried

`ElevatedToken` Yes = admin privileges; `LogonProcessName` User32 =
console, Advapi = service-style, Kerberos/NtLmSsp the package;
`ProcessName` is the requesting binary's full path.

## The privilege

ElevatedToken Yes + LogonProcessName shape.

## The path

ProcessName is the full binary path.
