# The carrier names the family

Depth module for `ctf-ai-ml`. Open `../SKILL.md` for the quick-reference
index first; this file is one named piece of the corpus - never a
finding by itself. A technique name is routing information, not a
finding.

A chat endpoint -> llm-attacks; a .pkl/.pt/.safetensors/.onnx file -> model-attacks; an image+classifier or a perturbation budget -> adversarial-ml. The artifact decides before any technique is chosen.
