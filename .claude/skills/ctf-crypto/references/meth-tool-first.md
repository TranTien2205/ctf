# tools/crypto first

Depth module for `ctf-crypto`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

`tools/crypto_attack.py list` (subcommand, NOT --list) names the implemented attacks - LLL, LCG, LFSR, ECC, HNP, integer attacks, bleichenbacher, franklin-reiter, smart - run the tool before re-implementing; stdlib-only by design.

## Pivot

Module read -> the shared file or class skill it names.
