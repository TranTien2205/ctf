# Documenting the chain — the chain card


After the flag: card the chain — the offsets, the gadget addresses
(offsets, not absolutes for PIE), the leak source, the ending.

## The card

- signals: the protection set + the confirmed IP control.
- first_confirming_probe: the cyclic offset + the first gadget
  landing.
- the chain: the gadgets + the args + the ending.
- traps: the alignment ret, the libc version, the side effects.
