# Artifact cell: prefetch / what-persists

Routing module for `dfir-sherlock-triage`. Question text +
artifact inventory -> one depth file. The router never answers
the question; it names who does.

Pairing `prefetch` / `what-persists`.

## Read

Strong-owner, partial, or ruled-out for this pairing - the
cell states the read and the one check that settles a
partial. Ruled-out cells are kept so the pairing is never
re-evaluated.
