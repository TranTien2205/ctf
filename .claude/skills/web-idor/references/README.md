# IDOR reference map

Open one named file after the two-identity ownership probe:

| Observed identifier shape | Reference |
|---|---|
| Sequential numeric ids | `sequential-enumeration.md` |
| Opaque or time-ordered ids | `uuid-analysis.md` |
| API object endpoint | `api-idor.md` |
| File/download object | `file-idor.md` |
| A bounded collection sweep is justified | `enumeration.md` |

The two-identity probe in `../SKILL.md` remains the proof boundary. Enumeration
material does not turn a guessed identifier or a public object into IDOR.
