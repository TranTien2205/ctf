# The geolocation workflow — reverse-search first

A photo/video frame is the artifact; the question is where it was
taken. Geolocation is matching unique visual detail against public
imagery — not guessing a city.

## The order

1. exiftool — embedded GPS ends it in one command.
2. Reverse image search (Google Lens, Yandex, Bing visual) — a hit
   names the place; check more than one engine.
3. Text in frame: signage, shop names, plates, road markings,
   driving side, utility poles, terrain, vegetation.
4. Sun + shadow: hemisphere from direction, latitude from length.
5. Architecture/infrastructure style -> map the candidate area
   against street-level imagery to confirm.

## The principle

A claimed location is proven by a public source showing the SAME unique feature — matching detail, not a similar place.

## Do not guess

A city guessed from a vibe is not geolocation — a unique feature matched to a public source is.

## The source

A public source showing the SAME unique feature — the confirmation standard.
