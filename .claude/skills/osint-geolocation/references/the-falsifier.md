# The falsifier — no distinguishing feature

No unique landmark, text, plate, sun angle or terrain feature
distinguishes the frame, and reverse search returns only generic
matches -> the frame carries too little to geolocate — record it.

## Featureless

No unique feature + generic reverse hits -> the frame is too thin to geolocate — record it.

## The close

Featureless frame + generic hits = the falsifier — record it, do not guess.
