# Confirming — the same unique feature

A claimed location is proven by a public source (street-level
imagery, a map, a reference photo) showing the same unique
feature — quote the matching detail and the source verbatim.

## The standard

Quote the matching detail + the public source — a coordinate only as strong as the feature under it.

## The same feature

Quote the matching detail + the public source — confirmation is the same unique feature, not a similar scene.

## Verbatim

The matching detail + the source — the strongest visual grade.
