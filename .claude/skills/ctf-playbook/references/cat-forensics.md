# Route: forensics

Entry-routing module for `ctf-playbook`. This file discriminates categories and manages the contest clock; it never solves - the category router it names does the next step.

Observed `PCAP, memory, disk, stego, logs` routes to `../../forensics-triage/`.

## What the router does

The thin router maps the sub-signal to exactly one depth file -
open it first; it is almost always enough.

## Depth handoff

Only after a class-level signal exists: ctf-forensics. Opening
depth before the router names it burns context and anchors the
hypothesis to the wrong class.

## Falsifier

The observation that says this category was wrong - a carrier the
table maps to a different row. Re-run skill_select on it rather
than forcing this route.
