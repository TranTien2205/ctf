# cache-poisoning vs host-header

Routing module for `web-triage`. This file discriminates - it says which bug class a signal raises and which probe separates the candidates. It never proves a class; proof belongs to the depth skill the route names.

A host-header value used in generated links is hosthdr; an unkeyed input stored in a cached response is cachep. The question: is the wrong value CACHED for others (cachep) or just reflected back (hosthdr).
