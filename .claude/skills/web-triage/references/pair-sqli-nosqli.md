# sqli vs nosqli

Routing module for `web-triage`. This file discriminates - it says which bug class a signal raises and which probe separates the candidates. It never proves a class; proof belongs to the depth skill the route names.

A string query vs an object-shaped filter: send a syntax marker - an SQL error or boolean delta says sqli; operators like $gt honoured inside a JSON body says nosqli. The datastore shape (24-hex ids, arrays) tips nosqli before probing.

## Pivot

skill the route selects.
