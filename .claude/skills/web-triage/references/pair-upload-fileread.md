# upload vs file-read via upload

Routing module for `web-triage`. This file discriminates - it says which bug class a signal raises and which probe separates the candidates. It never proves a class; proof belongs to the depth skill the route names.

An upload whose file is served back is file-upload; an upload whose path field reaches a read is fileread wearing an upload. The signal is whether the RESPONSE serves your content or the path names a file.
