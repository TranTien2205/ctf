# parser-differential vs smuggling

Routing module for `web-triage`. This file discriminates - it says which bug class a signal raises and which probe separates the candidates. It never proves a class; proof belongs to the depth skill the route names.

Two parsers disagreeing on the same bytes is the family; smuggling is the specific case where the disagreement lets a second request ride inside the first. Route parserdiff when the disagreement is semantic (headers, paths, encodings).
