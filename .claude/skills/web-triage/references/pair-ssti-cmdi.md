# ssti vs command injection

Routing module for `web-triage`. This file discriminates - it says which bug class a signal raises and which probe separates the candidates. It never proves a class; proof belongs to the depth skill the route names.

Both execute - the arithmetic marker separates them: {{7*7}} rendering 49 says the template engine evaluates; $(echo) or ;id appearing in output says a shell. ssti needs render context, cmdi needs exec context.
