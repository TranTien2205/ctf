# Acquisition formats — the full list

- .raw/.mem — flat dump, vol -f reads directly.
- .vmem — VMware suspended VM.
- .vmss/.vmsn — VMware snapshot.
- .dmp — Windows crashdump (PAGE/DU64) or minidump (MDMP).
- hiberfil.sys — hibernation (compressed).
- .lime — LiME Linux acquisition.
- .core — Linux core dump.
- pagefile.sys/swap — paged-out memory (strings surface here).
