# The profile — what windows.info gives

- Major/Minor + build — the OS version.
- NTBuildLab — the build string.
- DTB — directory table base.
- PsActiveProcessHead — process list head.
- PsLoadedModuleList — module list head.
- KdDebuggerDataBlock — debug block.
A plausible-looking pslist on a wrong profile is the failure mode.
