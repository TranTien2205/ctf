# The traps

- Forcing a generic pivot instead of extracting a rarer one.
- Treating a handle match as an identity — corroborate.
- Re-querying a source already recorded as a negative.
- Eyeballing a key instead of computing the fingerprint.

- Claiming an identity on one attribute.
- Skipping the normalisation (eyeballing a key).
- Re-querying a recorded dead end.
