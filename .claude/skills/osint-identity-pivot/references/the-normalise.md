# Normalise — compare like with like

- A key → its fingerprint (not the blob).
- An email → its pattern (local-part + domain separately).
- A handle → its canonical form (case, underscores).
- An image → a hash / a reverse-image query.
Raw forms don't compare; normalised forms do.

## The forms

Fingerprint, pattern, canonical handle, image hash — the normalised form is what makes two artifacts comparable.
