# Attribute → the source for it

- another account → namechk/WhatsMyName
- a real name → GitHub commit, keyserver, LinkedIn
- an email → commit headers, Gravatar, uid packets
- a location → bios, check-ins, posting details
- a domain → whois, linked sites
- a photo → avatar reverse-image, Gravatar

## Pick by attribute

The question names the attribute — pick the source that yields it.
