# Pivot → first pivots it buys

- rare handle → same handle on other platforms
- email → local-part handle + domain records
- name + org → talks, papers, commits
- PGP/SSH key → uid packets, authorized_keys
- avatar → reverse-image profile hits
- bio → exact-match cross-platform

## The strongest

A key fingerprint and an exact bio string are the most discriminating pivots.
