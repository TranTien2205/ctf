# Method: Claims vs observations

Depth module for `dfir-network-exfil-trace`. Open `../SKILL.md` for the
class contract first: first probe, falsifier, confirm shape, traps. This file
is one named piece of the corpus — never a finding by itself.

Layer the fields: SNI, Host header, destination hostname fields, filenames = CLAIMS (sender-asserted). `ip.dst`, byte counts, timestamps = OBSERVATIONS. A finding may cite a claim only beside the observation that grounds it.

## Why this order

Cheapest reliable measurement first; every stage emits a recordable row.
Skipping ranking to go straight to payload carving is how sessions spend
the budget on the wrong peer.
