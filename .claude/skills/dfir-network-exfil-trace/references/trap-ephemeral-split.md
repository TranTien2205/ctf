# Trap: Ephemeral ports split a channel

Depth module for `dfir-network-exfil-trace`. Open `../SKILL.md` for the
class contract first: first probe, falsifier, confirm shape, traps. This file
is one named piece of the corpus — never a finding by itself.

UDP/tunnelled flows keyed by ephemeral ports fragment one logical channel across many `conv` rows. Sum by `ip.dst` before ranking — a channel looks absent when it is really split.

## Defence

Quote the row with the headers/markers that disambiguate it, and say which
field/direction produced the number. When two readings are possible, quote
enough context that only one survives.
