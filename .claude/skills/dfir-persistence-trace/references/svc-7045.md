# Service: Event 7045  -  service installed (System)

Depth module for `dfir-persistence-trace`. Open `../SKILL.md` for the
class contract first: first probe, falsifier, confirm shape, traps. This file
is one named piece of the corpus  -  never a finding by itself.

SCM writes it with no audit policy needed  -  almost always present. Fields: `ServiceName`, `ImagePath`, `ServiceType` (hex: `0x1` kernel driver, `0x2` file-system driver, `0x8` recogniser driver, `0x10` own process, `0x20` share process), `StartType` (a STRING in the record  -  `autostart` spelled so in the Psmths sample; other spellings UNVERIFIED), `AccountName`. Microsoft's own 4697 triage rules: ImagePath outside %windir%/Program Files, ServiceType a driver value, or AccountName not localSystem/localService/networkService  -  fire `--on-match confirms` only after one of those rules hits.

## Evidence rule

A service claim needs the record AND the fields: 'a new service exists' is
surface; `ImagePath=C:\Users\Public\svc.exe` quoted from the 7045 row is
class evidence.

## Pivot

(`run-*`).
