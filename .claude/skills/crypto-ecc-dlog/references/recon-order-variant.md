# Recon order variant — the read, restated

## Read 1 — the artifact

What shape is the input: `sigs` list, `params` dict, `h = g^x` statement,
service endpoint, or a mix. `detection*.md`.

## Read 2 — the group

`p`/`a`/`b`/`G`/`n` or named curve. Named → nonce only. Custom → defect
ladder. `h = g^x` → `smoothness` gate.

## Read 3 — the signatures

Count, dedupe `r`, derive `z` (truncation first). `len ≥ required_signatures`
for any lattice plan.

## Read 4 — the oracle

Deterministic `k`? `r` repeats across different `m`? Validates submitted
points? Each is one probe.

## Read 5 — the deliverable

`d`/`x`/`k` → the flag step — sign/decrypt/format. Plan it before solving.

## Read 6 — the preconditions

`detection-checklist*.md` — every gate green before `crypto_attack.py`.
