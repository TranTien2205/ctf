# Log-analysis corpus index

The route files (the-*) hold the workflow, formats, fields,
methods, question shapes, evidence and falsifier. The format
matrices map each format by question and field. Start at
the-workflow and the-map-index.

## How to use it

- A specific format → its fmt-* module.
- A specific question → its q-* module or the fmt-question file.
- A specific field → the fmt-fld or f-field-q-* file.
- The discipline → the-workflow/evidence/falsifier/traps.
