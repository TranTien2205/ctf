# Closing — one line

A log file: **bracket it, distribute the field, window the
outlier.** The verbatim line + the count making it anomalous is
the evidence. A uniform log is the falsifier.

## The sequence

1. wc -l + head/tail — volume + timeframe.
2. log_summary.py summary — the auto-bracket + distributions.
3. cut|sort|uniq -c|sort -rn — the field's anomaly.
4. grep -n + window — the line and its context.
5. Rotated siblings — the earlier window.
6. Quote the line + the count — that's the finding.
