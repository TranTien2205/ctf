# Case studies

- **`next_prime` keygen** → `fermat` — `q=p+small` → `a²-n` square → split.
- **`e`=3 broadcast** → `hastad` — CRT + cube root.
- **small-`d` device** → `wiener`/`boneh-durfee` — `e`≈`n`.
- **a `.json` batch** → `batch-gcd` — a `gcd>1` collision.
- **partial `.pem`** → `coppersmith`/`crt`/`factor-from-d` — the non-redacted field.
- **two `e`, one `n`** → `common-modulus` — Bezout.
- **`gcd(e,phi)>1`** → `eth-root` — the `g` candidates.
See `case-studies-deep.md` for the annotated shapes.
