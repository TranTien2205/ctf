# The transform check

Routing module for `rev-triage`. The pipeline is identify, decompile, find the deciding check, replicate it - this file is one named step or artifact; it never analyzes for you.

Input through a reversible transform (xor, add, permute,
substitute) compared to a constant - invert the transform on
the constant; the check carries its own solution.
