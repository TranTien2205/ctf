# Defender: Defender 5007 — config changed

Depth module for `dfir-antiforensics-trace`. Open `../SKILL.md` for the
class contract first: first probe, falsifier, confirm shape, traps. This file
is one named piece of the corpus — never a finding by itself.

`MALWAREPROTECTION_CONFIG_CHANGED`. Microsoft documents exactly two fields, `Old value` and `New value`, described only as 'Old/New antivirus configuration value' — it does NOT document a path field. In practice `New value` carries the full changed registry value path, so an Add-MpPreference exclusion reads as `HKLM\SOFTWARE\Microsoft\Windows Defender\Exclusions\Paths\<path>`. Read the string, do not assume the shape.

## Evidence rule

Defender events carry few fields — quote the message text and the event id
together; the symbolic name is documentation, the message is the record.
