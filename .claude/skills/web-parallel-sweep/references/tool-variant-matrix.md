# variant_matrix.py

Method module for `web-parallel-sweep`. The sweep splits a web target by bug-class family into bounded measurements; this file is one named piece of that method. Ten families reporting is not ten families closed.

One request per payload SHAPE at one injection point across ten
families, baseline-diffed on status/length/markers/Location/
timing, ranked, negatives counted. --dry-run sends nothing;
a confirms verdict only on a marker hit.
