# Question: which families park

Method module for `web-parallel-sweep`. The sweep splits a web target by bug-class family into bounded measurements; this file is one named piece of that method. Ten families reporting is not ten families closed.

A family whose source_signals_that_fired is empty is the cheapest
to park - nothing in the source points at it. A family in the
kill map gets no agent; read its measurement and reopen_if.
