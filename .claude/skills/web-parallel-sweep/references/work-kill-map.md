# Write the dead families down

Method module for `web-parallel-sweep`. The sweep splits a web target by bug-class family into bounded measurements; this file is one named piece of that method. Ten families reporting is not ten families closed.

Every family whose falsifier HELD goes into knowledge/attempts/
<challenge>.json with its measurement - or the next attempt
re-walks it, which is the failure this method exists to prevent.
