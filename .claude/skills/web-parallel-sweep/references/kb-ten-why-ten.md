# Why ten families

Method module for `web-parallel-sweep`. The sweep splits a web target by bug-class family into bounded measurements; this file is one named piece of that method. Ten families reporting is not ten families closed.

The split follows probe-shape similarity, and ten is what
the probe shapes produce - the number is derived, not
chosen; adding a class joins an existing family or
justifies a new one by its probe shape.

question names.
