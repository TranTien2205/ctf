# Cell: parser uses variant-matrix

Method module for `web-parallel-sweep`. The sweep splits a web target by bug-class family into bounded measurements; this file is one named piece of that method. Ten families reporting is not ten families closed.

Whether the `parser` family reaches for the `variant-matrix` primitive.

## Fit

A family uses a tool when its probe shape matches the tool's - the
cell states which of the family's classes this pairing serves and
what the tool's baseline/negative discipline contributes to the
measurement. A pairing that never applies is stated as none, not
omitted - knowing a family does NOT need a tool is part of the map.

## Discipline

The tool's output feeds the contract's evidence field - verbatim
excerpts only, and a tool's negative count belongs in the family's
disposition.
