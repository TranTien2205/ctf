# Wayback Machine and public caches — case catalogue

Deleted content persists: the Wayback Machine, Google cache, and archive.today hold the endpoint's history — a CTF-legitimate source when the artifact used to be public.

## Cases

| # | Shape | Meaning | Route |
|---|---|---|---|
| 1 | challenge history on archive.org | old versions | read removed routes |
| 2 | deleted page in Google cache | cached content | read the snapshot |
| 3 | old robots.txt in wayback | historical hidden paths | probe current state |

## Falsifier

Falsifier — no snapshots or the artifact never was public: channel empty.
