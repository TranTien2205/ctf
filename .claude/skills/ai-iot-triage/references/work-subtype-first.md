# Sub-type before anything

Routing module for `ai-iot-triage`. AI and IoT share nothing but the label - this file names the sub-type and the router that owns it; it never solves.

The category is not standardised across events - a chat endpoint, a
model file, a firmware image, a protocol capture, and an embedded
binary are five different challenges sharing one label. The carrier
decides the branch before any technique.

## Pivot

Module read -> the router or skill the boundary names, or the sibling
module the artifact points to.
