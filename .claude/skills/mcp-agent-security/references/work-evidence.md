# The model's text is not evidence

Depth module for `mcp-agent-security`. Open `../SKILL.md` for the
two-half framing first (offensive vs defensive); this file is one
named piece of the corpus - never a finding by itself. A model's
own text is never evidence of a flag.

A flag is only real when it comes from a tool result, a file, or a challenge-produced response - the model asserting 'the flag is X' is the most common fabricated-answer shape in the whole toolkit.
