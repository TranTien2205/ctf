# The lethal trifecta

Access to private data + exposure to untrusted content +
an outbound channel - the three-property combination that
makes an agent exploitable end-to-end. The audit counts
the properties; removing any one breaks the chain.

## Audit

Private data? Untrusted input? Outbound channel? All
three is the trifecta; the finding names which property
to remove.
