# Choosing the exfil channel

The reachable outbound surface bounds the attack: a fetch
tool's argument, a render surface, the answer text itself.
The chain needs exactly one reachable channel; more is
waste, none is a reclassify.

## Check

From the map: which tools make outbound requests, which
render surfaces exist, whether the answer itself is
observable.

## Pivot

Module read -> the base reference files or the class boundary it names.
