# The falsifier list — the closing observations — checklist

Companion to `the-falsifier-list.md`.

## Checklist

- [ ] No compare reaches the verdict → wrong class.
- [ ] The compare is vs a run-time value you can't produce → replicate
- [ ] The "check" is a VM dispatch → the VM class.
- [ ] The input does something (overflows) → a pwn class.
