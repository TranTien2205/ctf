# Native-check glossary — checklist

Companion to `the-glossary.md`.

## Checklist

- [ ] Term | Meaning
- [ ] the deciding check | the one compare gating the verdict
- [ ] the verdict | the success/failure print the check guards
- [ ] the xref | a code reference to an address — the backwards path
- [ ] the transform | the f(input) the check applies before comparing
- [ ] the expected | the stored/constant compare side
- [ ] replication | re-implementing the check in Python
- [ ] the patch | flipping the deciding branch
- [ ] the oracle | an observable distinguishing right from wrong bytes
