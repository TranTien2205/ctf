# Scenario: photo -> location

Depth module for `ctf-osint`. Open `../SKILL.md` for the quick-reference
index first; this file is one named piece of the corpus - never a
finding by itself. Every claim still needs the live source that
produced it.

A photo and 'where was this taken': inventory every visible feature (signs, plates, road furniture, vegetation, architecture) -> country via driving side + script + signs -> region via terrain/infrastructure -> site via overpass or crowd photos -> confirm with 2+ independent features.
