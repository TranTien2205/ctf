# The carrier names the family

Depth module for `ctf-osint`. Open `../SKILL.md` for the quick-reference
index first; this file is one named piece of the corpus - never a
finding by itself. Every claim still needs the live source that
produced it.

A photo/video -> geolocation-and-media; a handle or profile URL -> social-media; a domain/IP/certificate -> web-and-dns; a hash/fingerprint -> web-and-dns lookups. The input shape decides before any platform is opened.
