# Pivot discipline

Depth module for `ctf-osint`. Open `../SKILL.md` for the quick-reference
index first; this file is one named piece of the corpus - never a
finding by itself. Every claim still needs the live source that
produced it.

One unique pivot per challenge: a handle, a photo, a domain, a hash. Work that pivot through one source at a time; a second pivot only starts when the first is exhausted AND recorded.
