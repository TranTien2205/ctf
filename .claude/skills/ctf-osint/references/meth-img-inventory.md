# Image feature inventory

Depth module for `ctf-osint`. Open `../SKILL.md` for the quick-reference
index first; this file is one named piece of the corpus - never a
finding by itself. Every claim still needs the live source that
produced it.

Before any search: list EVERY feature - text, signs, plates, furniture, vegetation, architecture, terrain, sky. The inventory bounds the search; a missed feature is a wasted hour.
