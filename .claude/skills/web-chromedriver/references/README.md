# web-chromedriver — reference index

A verified-class skill: the local-bot-debugging pattern is anchored by
`apexsurvive`, and the tunnel-interstitial trap by `tornadoservice`.

## The two uses

- **debugging aid** — reproduce the challenge's admin bot locally so a
  client-side payload is a normal debug loop, not a blind channel.
- **attack surface** — a driver/Grid/CDP endpoint the challenge exposes
  is a file-read and loopback capability.
