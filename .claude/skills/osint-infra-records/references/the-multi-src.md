# Correlating sources

A SAN-named host + a passive-DNS IP + a whois pattern — the sources
corroborate each other; cite the ones that agree.

## The correlation

- A SAN names a host; passive DNS shows where it pointed.
- whois names the registrant; the same registrant owns siblings.
- The live cert + crt.sh history agree on which names existed.
Two sources agreeing is stronger than one.
