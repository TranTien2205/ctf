# Passive DNS — the history

Passive DNS (SecurityTrails, VirusTotal, etc.) shows historical
resolutions — a host/IP that no longer answers. For a changed
record the history is the answer.

## When it matters

- A SAN-named host that no longer resolves — passive DNS shows
  what it once pointed to.
- A changed IP — the old host it pointed at.
- Sibling domains sharing a historical IP.
