# The offset question

Routing module for `pwn-binary-triage`. This file names the protections, the IP-control proof, and the depth file the route selects; it never writes the exploit.

How far the return address sits from the input - cyclic
patterns (or hand-built De Bruijn) find it from the crash
value. The offset is the first number the exploit needs.
