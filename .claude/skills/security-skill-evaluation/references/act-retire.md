# Action after verdict: retire

Method module for `security-skill-evaluation`. Measured by what
it changes in sessions, never by how much text it holds.

The concrete edit sequence when a skill earns `retire`:
the front-matter change, the registry/index regen, the
field-note entry, and the commit convention for the
change.

## Guard

What must NOT happen with this verdict (a catalogue
skill never claims local experience; a retired skill's
links get redirected).
