# Metric depth: session-credit

Method module for `security-skill-evaluation`. Measured by what
it changes in sessions, never by how much text it holds.

The `session-credit` metric in full: its exact definition, the data
source that feeds it, the failure mode it catches, and the
threshold that triggers a review.

## Collection

Where the numbers come from (ledger rows, field notes,
gate runs) and the sampling caveat - a metric over two
sessions is noise, not signal.
