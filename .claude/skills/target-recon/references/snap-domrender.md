# Visual recon: domrender

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

DOM-render recon: the post-JS DOM carries links
and forms the raw HTML lacks - rendered hrefs, framework
data attributes, dynamically-injected endpoints. Compare
raw-vs-rendered: the DELTA is the JS-driven surface
inventory.
