target into the signals classify.py and the routers consume.

wordlist, and every observation recorded verbatim.

entry page catches what HTML hides - rendered UI state,
client-side-only content, branding/device identity, default
admin portals. playwright/selenium are installed; one shot
per unique surface, never per probe.
