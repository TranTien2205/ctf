# Passive recon: whois

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

whois the domain: registrar, creation date (a
week-old domain = purpose-built CTF infra), name servers =
hosting provider signal. CTF instances usually sit on fresh
infrastructure; a 10-year-old corporate domain on a challenge
port is itself the odd observation worth recording.
