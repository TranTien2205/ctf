# Second-order surface: secondorder

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Second-order surface recon: values stored and
rendered elsewhere - registration fields appearing in admin
views, search terms in logs, user-agent in analytics pages.
Recon names WHERE the value lands (a profile view, an admin
dashboard) not just where it entered - the stored-sink map.
