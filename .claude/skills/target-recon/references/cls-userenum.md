# Class recheck: userenum

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Recon evidence web-userenum needs: the oracle
candidates - login error message (verbatim), password-reset
response (same vs different for dead vs live user), register
duplicate-user signal, timing deltas across attempts, and
directory-style endpoints (wp/v2/users, /users/<name>).

Signal harvested -> out-*; route named -> that skill.
