# Baseline calibration: wildcardcheck

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Wildcard check: does the server 404 at all?
3 dead paths -> identical 200-shape responses = wildcard/catch-
all = SPA-style or lazy app. The discriminator then becomes
content/length, not status. Record which discriminator works.
