# Param-level recon: reflectcheck

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Per-param reflection check: send a unique
marker (x7q2z) - where does it come back? HTML body, attribute,
JS context, JSON field, error message, header. The CONTEXT is
the observation: 'marker reflected inside <script>' is a
different class prior than 'reflected in error text'.
One marker per param - cheap, decisive.
## Pivot

Signal harvested -> out-*; route named -> that skill.
