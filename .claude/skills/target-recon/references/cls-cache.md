# Class recheck: cache

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Recon evidence web-cache-poisoning needs: cache layer
identity (cf-cache-status, x-cache, age, via), cacheable
path posture (static only? dynamic cached?), cache keys
visible (vary header, query keys included?), and unkeyed
input candidates (headers, cookies the key ignores).
