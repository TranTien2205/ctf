# WebSocket recon: handshake

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

WebSocket handshake recon: GET with Upgrade:
websocket + Sec-WebSocket-Key - 101 Switching Protocols =
channel confirmed; the Sec-WebSocket-Protocol subprotocol
list, extensions, and Origin check presence/absence are the
three observations. Origin un-checked = cswh class weight.
