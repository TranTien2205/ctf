# Second-order surface: blindchannel

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Blind-channel surfaces: parameters whose
effect never returns (feedback forms, webhooks that fire
later, async jobs, emails) - the observable channel is
timing/error/log-side-effects. Recon names which params are
blind-shaped; the class skills pick the oracle type.
## Pivot

Signal harvested -> out-*; route named -> that skill.
