# Param discovery: harmining

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

HAR mining: a browser session captured to .har
carries every real request - path, method, params, headers,
cookies - exactly as the app expects them. Replaying the
shapes (not the session) names params that forms and JS hide:
tracking fields, feature flags, API versioning.
## Pivot

Signal harvested -> out-*; route named -> that skill.
