# Passive recon: github

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Code-search the domain/app name on public repos:
leaked endpoints, config examples, old keys, issue trackers
naming internal routes. Strictly public information and recon
only - a leaked key is recorded as an observation; whether it
works is a separate authorized test the controller gates.
## Pivot

Signal harvested -> out-*; route named -> that skill.
