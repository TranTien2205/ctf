# Recon trap: waftrigger

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Trap: triggering the WAF early. One sqli-
shaped probe in recon can block the source IP for everything
that follows - keep recon payloads neutral until the WAF's
existence is measured, then enumerate through what it allows.
