# Passive recon: wayback

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

web.archive.org CDX API for the domain: historical
endpoints, removed parameters, old JavaScript with live-looking
secrets, paths that 404 now but reveal the stack. Filter for
status 200 captures; the endpoint list is an enumeration seed,
never a claim the path is live now.
