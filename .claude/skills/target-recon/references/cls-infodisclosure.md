Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.

wordlist, and every observation recorded verbatim.

Recon evidence web-info-disclosure needs:
the exposed-artifact inventory (git/env/backup/listing hits
from pe-*), debug surfaces open, version strings harvested,
error verbosity observed, static maps, comments in HTML/JS -
the whole oddity list, each with verbatim evidence.
