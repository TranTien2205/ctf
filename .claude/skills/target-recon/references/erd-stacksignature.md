# Error depth: stacksignature

Reference module for `target-recon`. Recon turns a supplied live
target into the signals classify.py and the routers consume.
Bounded: the supplied port/path only, three commands before any
wordlist, and every observation recorded verbatim.

Error-page stack signature: the 404/500
body style names the framework without any header - Whitelabel
= Spring, 'Cannot GET /x' = Express, yellow traceback = Django/
Werkzeug, Tomcat 'message /x description' = Java servlet,
nginx default page = bare proxy. Each shape is one recorded
signal feeding fx-*.
## Pivot

Signal harvested -> out-*; route named -> that skill.
