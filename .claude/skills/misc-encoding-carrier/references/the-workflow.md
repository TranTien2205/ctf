# The workflow — identify, decode, measure

1. enc_detect -> the decode chain.
2. Standard decoders; decode until plain or a layer fails.
3. cipher_id -> IC/frequency when no carrier matches.
4. classical_solve for a named cipher; esolang_run for a program.
5. Confirm: plaintext or the flag.

## The order

enc_detect -> decoders -> cipher_id -> classical_solve/esolang_run.

## The order

Identify -> decode -> measure -> cipher/esolang -> plaintext/flag.
