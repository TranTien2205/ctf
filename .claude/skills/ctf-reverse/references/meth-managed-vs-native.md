# Managed vs native split

Depth module for `ctf-reverse`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

.NET/Java/Python-bytecode get decompilers (rev-managed-code / rev-bytecode-vm cover them); native gets disassembly. The file magic decides which shared file - languages.md carries the per-language specifics.
