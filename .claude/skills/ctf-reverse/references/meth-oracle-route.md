Depth module for `ctf-reverse`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

Companion to `meth-oracle.md`.

## When to open the base

When the binary's shape or the question lands on this topic - the
base module carries the technique detail; this card only carries
the routing decision.

## Inputs it needs

The triage result (file type, protections, imports, language) and
the question shape. If the artifact the base names is absent, the
topic is 'not checkable' - not 'absent'.

## Outputs it feeds

A named technique with its citation (disassembly excerpt, constant,
decoded string), or a recorded negative pointing at the next file.

## Neighbours

The shared-file families it sits between per `agg-index`: tools*,
anti-analysis*, patterns*, languages*.
