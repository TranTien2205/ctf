Depth module for `ctf-reverse`. Open `../SKILL.md` for the shared-file
index first; this file is one named piece of the corpus - never a
finding by itself.

No strings != no text: stack strings (mov-immediate chains), XOR-encrypted blobs decoded at init, computed names - look for the decoder loop near entry, not the string table.
